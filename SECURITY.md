# Security Policy

## Reporting Security Issues

We take the security of this project and its users seriously. If you discover a security vulnerability or suspect a secret leak in this repository, please disclose it responsibly.

### How to Report

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send a private email with details of the vulnerability to:
- **Email**: [steve.rock@wheelhouser.com](mailto:steve.rock@wheelhouser.com)
- **Subject**: `[SECURITY VULNERABILITY] Antigravity IDE Packaging`

### What to Include in Your Report

To help us triage and investigate the issue as quickly as possible, please include:
1. A clear description of the vulnerability and the potential impact.
2. The affected files, scripts, spec files, or repository revisions.
3. Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
4. Any potential mitigations or patches you have identified.

### Response Commitment

- We will acknowledge receipt of your vulnerability report within 48 business hours.
- We will coordinate a fix, verify it across test environments, and push the resolved package to the public repository.
- We will credit you in the release notes / changelog (if you desire).

### Upstream Google Antigravity Security

Note that this repository contains open-source packaging and launcher integration scripts for Linux distributions. If you discover a vulnerability within Google Antigravity itself (the application payload), please report it directly through Google's Vulnerability Disclosure Program at [bughunters.google.com](https://bughunters.google.com/).
